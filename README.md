# Aryan Bisht - Portfolio Website

This is a personal portfolio website for **Aryan Bisht**, showcasing skills, projects, and contact information. The website is built using **HTML, CSS, and JavaScript**, featuring animations, dynamic content, and theme toggling.

## 🚀 Features

- **Responsive Design**: Optimized for all screen sizes.
- **Theme Toggle**: Light/Dark mode support.
- **Particles.js Background**: Interactive visual effects.
- **Projects Showcase**: Displays featured projects.
- **Dynamic Navigation**: Smooth scrolling and page transitions.
- **Contact Form**: Visitors can send messages directly.

## 🎨 Technologies Used

- **HTML5**: Structure of the website
- **CSS3**: Styling and layout design
